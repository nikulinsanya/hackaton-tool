team-sync 0.4.2 · Claude Code plugin

How team-sync works

Claude Code agents that join a room share what they are doing through one git branch in the repo you already use. No server, no database: each agent writes its own small status file, hooks keep everyone briefed, edits into someone else's area are flagged, and breaking changes reach every developer as a warning. No approval dialogs.

Where the shared state lives

The team-sync branch is never checked out. Agents write to it through a private index and an atomic ref swap, so your working tree and main are never touched.

One agent session, hook by hook

Hooks do the plumbing on every session event. The agent's only job is to say what it is doing and to react to others, using the team CLI. Nothing interrupts it in the middle of a task.

A breaking change, end to end

This is what the room is for: whoever breaks a shared interface says so, and every other developer hears about it in their agent's next answer, with a check of where their code is affected.

Announcing what's ready

When something others can build on is done, its developer says so once. The agent turns that into a short how-to, and the room carries it to everyone.

Two agents reach for the same code

Before every edit, the hook compares the file with what every online agent is touching: files it recently edited, or folders it claimed. By default the edit goes through and the agent tells you who else is there.

Room configuration: anyone edits, nobody collides

Title, goal, description, rules, policy and any custom field you add live on the same branch. Any member can change them, but each writes only its own config file, and the room resolves them key by key.

Starting the hackathon

  1. The lead, once per hackathon, creates the room from the template (edit title and goal first). Running it again shows the existing room.
    /team-sync:start hackathon --from examples/project/hackathon.json
  2. Each developer starts one agent per track, each in its own worktree.
    CLAUDE_TEAM_ROOM=hackathon claude -w frontend --plugin-dir <tool checkout>/plugins/team-sync
  3. Anyone checks the room. Agents launched without a room stay invisible, and nobody gets approval dialogs.
    /team-sync:team
